# LLM 應用與 Prompt Engineering

> 狀態：教學初稿，待人工確認

## 一、基本定義

Prompt Engineering（提示工程）是設計與改善輸入指令的方法，目的是讓模型更清楚理解任務需求。

## 二、原理說明

良好的 Prompt 可以提供明確的任務、必要背景、限制條件與期望的輸出格式。LLM 常被應用於文字摘要、翻譯與問答等工作。

## 三、生活化例子

較模糊的提問：「幫我整理文章。」較清楚的提問：「請將這篇文章整理成三個重點，使用繁體中文，每點不超過50字。」
